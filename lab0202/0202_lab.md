### 2.3. Задачи для выполнения

#### Блок 1. Базовый синтаксис (3 задачи)

**Задача 1.1. «Функция приветствия»**

Напишите функцию `greetUser(name: String, age: Int): String`, которая возвращает строку с приветствием пользователя и указанием его возраста через 10 лет.

**Пример:**
```kotlin
greetUser("Анна", 25) // "Привет, Анна! Через 10 лет тебе будет 35 лет."
```

---

**Задача 1.2. «Определение времени года»**

Напишите функцию `getSeason(month: Int): String`, которая по номеру месяца (1–12) возвращает название времени года:

| Месяцы | Время года |
|:---|:---|
| 12, 1, 2 | Зима |
| 3, 4, 5 | Весна |
| 6, 7, 8 | Лето |
| 9, 10, 11 | Осень |

**Требования:**
- Используйте `when` вместо `if-else`.
- Если месяц вне диапазона 1–12, верните `"Некорректный месяц"`.

---

**Задача 1.3. «Факториал числа»**

Напишите функцию `factorial(n: Int): Long`, которая вычисляет факториал числа n (n ≥ 0).

**Требования:**
- Используйте **рекурсию** с ключевым словом `tailrec` для оптимизации.
- Для n < 0 верните `-1`.

**Пример:**
```kotlin
factorial(5) // 120
factorial(0) // 1
factorial(-3) // -1
```

#### Блок 2. Null-безопасность (2 задачи)

**Задача 2.1. «Безопасное приведение строки к числу»**

Напишите функцию `parseIntSafe(str: String?): Int?`, которая пытается преобразовать строку в целое число.

**Требования:**
- Если строка равна `null`, верните `null`.
- Если строка не является числом, верните `null`.
- Используйте функцию `toIntOrNull()`.

**Пример:**
```kotlin
parseIntSafe("123")   // 123
parseIntSafe("abc")   // null
parseIntSafe(null)    // null
```

---

**Задача 2.2. «Обработка списка с null-элементами»**

Напишите функцию `filterNonNullAndDouble(list: List<Int?>): List<Int>`, которая:
1. Фильтрует `null`-элементы.
2. Удваивает каждый оставшийся элемент.
3. Возвращает новый список.

**Требования:**
- Используйте цепочку функций высшего порядка (`filterNotNull`, `map`).

**Пример:**
```kotlin
filterNonNullAndDouble(listOf(1, null, 3, null, 5)) // [2, 6, 10]
```

#### Блок 3. Коллекции и функции высшего порядка (3 задачи)

**Задача 3.1. «Средний возраст»**

Напишите функцию `averageAge(people: List<Person>): Double`, где `Person` — это `data class` с полями `name: String` и `age: Int`.

**Требования:**
- Используйте `map` и `average()`.
- Если список пустой, верните `0.0`.

---

**Задача 3.2. «Группировка по первой букве»**

Напишите функцию `groupByFirstLetter(words: List<String>): Map<Char, List<String>>`, которая группирует слова по первой букве.

**Требования:**
- Используйте `groupBy { }`.
- Приведите первую букву к верхнему регистру.

**Пример:**
```kotlin
groupByFirstLetter(listOf("apple", "apricot", "banana", "blueberry"))
// {
//   'A' -> ["apple", "apricot"],
//   'B' -> ["banana", "blueberry"]
// }
```

---

**Задача 3.3. «Поиск самого длинного слова»**

Напишите функцию `findLongestWord(words: List<String>): String?`, которая возвращает самое длинное слово в списке.

**Требования:**
- Используйте `maxByOrNull { it.length }`.
- Если список пустой, верните `null`.

#### Блок 4. Корутины (Coroutines) — 2 задачи

**Задача 4.1. «Асинхронная задержка»**

Напишите `suspend`-функцию `delayedPrint(message: String, delayMs: Long)`, которая:
1. Печатает сообщение.
2. Ждёт указанное количество миллисекунд (используя `delay`).
3. Печатает сообщение `"Готово!"`.

**Требования:**
- Используйте `runBlocking` для тестирования в `main`.

**Пример вывода:**
```
Начинаем...
(ждём 2 секунды)
Готово!
```

---

**Задача 4.2. «Параллельное выполнение задач»**

Напишите функцию `runParallelTasks()`, которая запускает **три** асинхронные задачи с разными задержками:
- Задача 1: задержка 1 секунда, возвращает `"Результат 1"`.
- Задача 2: задержка 2 секунды, возвращает `"Результат 2"`.
- Задача 3: задержка 3 секунды, возвращает `"Результат 3"`.

**Требования:**
- Используйте `async` / `await`.
- Выведите результаты в том порядке, в котором они завершились.

1. **Документирование кода (KDoc):**
   - Все объекты и функции должны иметь KDoc-комментарии.
   - Каждый параметр и возвращаемое значение должны быть описаны.
   - Должны быть примеры использования (в формате `@sample` или в тексте).

2. **Стиль кода:**
   - Следуйте официальному **Kotlin Coding Conventions**.
   - Используйте `val` для неизменяемых переменных, `var` только где необходимо.
   - Избегайте `!!` (non-null assertion) — используйте безопасные операторы.

3. **Тестирование:**
   - В функции `main()` должны быть тесты для каждой задачи с выводом результатов.

```markdown
Закрепить знания по Kotlin, научиться работать с null-безопасностью, коллекциями и корутинами.

## Что было сделано
<!-- Кратко опишите этапы -->
1. Настроил среду разработки на Debian (установил Kotlin, IntelliJ IDEA).
2. Реализовал 8 задач по базовому синтаксису, null-безопасности и коллекциям.
3. Реализовал 2 задачи с использованием корутин.
4. Написал KDoc-комментарии для всех функций.
5. Создал тесты в `main()` для проверки решений.
6. Загрузил проект на GitHub.

## С какими сложностями столкнулись
1. **Сложность:** Поначалу было непривычно использовать `tailrec` для рекурсии.
   - **Решение:** Изучил документацию и примеры, понял, что это оптимизация хвостовой рекурсии.

2. **Сложность:** Освоение корутин — `async` и `await` казались сложными.
   - **Решение:** Написал несколько простых примеров, потом перешёл к основной задаче.

3. **Сложность:** Разобраться с `groupBy` и лямбда-выражениями.
   - **Решение:** Использовал `it.first().uppercaseChar()` для группировки по первой букве.

## Что нового узнали
- Как работают `tailrec`-функции и зачем они нужны.
- Null-безопасность в Kotlin: операторы `?.`, `?:`, `!!`.
- Функции высшего порядка: `filter`, `map`, `reduce`, `groupBy`.
- Основы корутин: `launch`, `async`, `await`, `delay`.
```

```bash

# Запуск
java -jar Hello.jar
```
